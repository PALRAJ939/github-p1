# Resume Truthfulness Checker

A modern, interactive web app that analyzes and verifies the credibility of resume claims.

## Features

✨ **Intelligent Analysis**
- Evaluates resume claims for truthfulness and credibility
- Checks for quantifiable metrics, specific time periods, and measurable impact
- Identifies red flags like vague language and unrealistic superlatives

📊 **Detailed Feedback**
- Shows credibility score (0-100%)
- Categorizes claims as Credible, Moderate, or Questionable
- Provides specific factors that influenced the score
- Displays overall assessment across multiple claims

🎨 **Modern UI**
- Clean, gradient-based design
- Responsive layout (works on desktop and mobile)
- Smooth animations and transitions
- Visual score indicators

## How It Works

The analyzer examines:
1. **Positive Factors** - Specific metrics, action verbs, impact statements, technical depth
2. **Red Flags** - Vague language, unrealistic claims, unverifiable statements
3. **Context Matching** - Validates claims against supporting context

## Usage

Simply open `index.html` in any modern web browser. No setup or installation required!

### Example Claims

**High Credibility (70%+):**
- "Led a team of 5 engineers to build a real-time analytics platform that increased user engagement by 45% within 6 months"

**Moderate Credibility (40-70%):**
- "Worked on several web development projects using React and Node.js"

**Low Credibility (<40%):**
- "I'm an expert in everything and a software engineering rockstar ninja"

## Tips for Writing Credible Resume Claims

✅ **DO:**
- Include specific numbers and metrics (% improvement, user count, revenue impact)
- Use strong action verbs (led, architected, implemented, optimized)
- Mention measurable business outcomes
- Specify time periods and durations
- Show technical depth

❌ **DON'T:**
- Use vague language ("worked on", "helped with")
- Make unrealistic claims ("master", "ninja", "expert in everything")
- Include unverifiable statements
- Overuse superlatives
- Be passive about your accomplishments
